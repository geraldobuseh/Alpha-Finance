# PQL-020: SPY buy-and-hold control

Hypothesis: pairing every new paper account with an equally funded, independently
held SPY control provides a meaningful baseline for later strategy comparisons.
Problem: only generic arbitrary-capital portfolios exist; nothing creates a paper
account and its invested control together. Learning objective: equal capital,
consistent costs, independent state and explicit benchmark assumptions.
Generation target: SpyBuyAndHold strategy and PaperPortfolioPair creation boundary.
Resolution signal: both start with $1,000, SPY is bought once, and price changes
value the control without further orders or fees.

## Creation and use

Include `simulation/paper_portfolio_pair.hpp` and link `pql_simulation`.

```cpp
const auto spy = pql::Symbol::create("SPY").value();
const pql::Timestamp start{pql::Timestamp::Value{std::chrono::milliseconds{10}}};
const pql::MarketState initial{spy, pql::Price::create(100).value(), start};
const pql::TradingCosts costs{pql::Money::create(1).value(), 5};
auto pair = pql::PaperPortfolioPair::create(
    pql::PortfolioId::create(1).value(), pql::PortfolioId::create(2).value(),
    pql::OrderId::create(1).value(), initial, costs);
if (!pair) {
    // Report setup failure; never use an uninvested cash account as the benchmark.
    return;
}
const auto paper_input = pair->paperState();     // Detached strategy observation.
const auto control = pair->benchmarkState();    // Detached control for valuation.
// Submit strategy proposals with pair->executePaper(order, market).
// Value both snapshots at the same comparison time with totalValue(marks).
```

Portfolio IDs must be distinct and caller-supplied. Order IDs remain caller-managed;
the initial benchmark order ID belongs to its own portfolio namespace. This is an
in-memory creation boundary, not a database ID allocator or persisted association.

The factory has no starting-capital argument: both accounts always start at $1,000.
It stages both privately and returns only after the benchmark buy succeeds. Invalid
SPY identity, infeasible sizing or broker rejection returns nullopt. Allocation
errors may propagate before publication; no caller-owned financial state changes.
Generic Portfolio::create and persistence remain arbitrary-capital primitives for
replay, real accounts and tests; paper creation should use this new boundary.

## Purchase and hold policy

SpyBuyAndHold implements Strategy. On a pristine snapshot and exact uppercase SPY
quote, it proposes one market buy with fractional shares. Quantity is
(cash - commission) / slipped buy price, using the same TradingCosts::executionPrice
calculation as FakeBroker. If division rounds to an unaffordable amount, the budget
and quantity are conservatively stepped toward zero before creating the order.
The recomputed total must still fit; no epsilon overdraft or cash repair is allowed.
Actual residual cash is retained and earns no interest.

Wrong-symbol observations, non-pristine snapshots and infeasible/unrepresentable
sizing yield no strategy proposal. The pair converts failure to obtain an initial
fill into explicit setup failure. Existing accepted ledger history makes subsequent
strategy instances hold; there is no fragile in-memory 'already bought' flag.

The pair exposes no benchmark execution method. executePaper applies only to the
paper account, using the same commission and slippage configuration as the control.
Both order and execution timestamps must be at or after inception. Pair copies own
independent accounts; assignment is deleted to prevent partial cross-account copies.
No stored broker reference can point into an earlier copy of the pair.

## Numeric control

With explicit zero costs, SPY at $100 buys 10 shares. The paper account holds $1,000
cash. At a later SPY mark of $110, the control is worth $1,100 while an untouched
paper account remains $1,000. At $90, the control is worth $900: it does not sell or
rebalance in response. Equal starting money is the comparison baseline.

At a $99 quote with a $10 commission and zero slippage, the control buys 10 shares,
holds zero cash and has $100 average cost. Initial market value is $990, reflecting
the fee; a later $109 mark yields $1,090. Equal starting capital does not mean equal
post-execution value. More paper trades can incur more costs than buy-and-hold.

## Limits and validation

This is a raw-price SPY control, not total return: dividends, corporate actions,
taxes and interest are not modeled. Supply marks at matching decision horizons;
the current snapshot valuation API does not enforce historical data availability.
No future provider query, performance metric, dashboard, scheduler or persistent
pair mapping is introduced. Fixed cost assumptions do not establish liquidity.

Seven tests cover funding, holding, independence, fractional sizing, the $0.21
division-overspend regression, identical costs, setup failure, chronology and replay.
Review and runtime evidence are in `.codex/reviews/PQL-020/`.
